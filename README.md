# LP Beauty Nails - Site vitrine

Site vitrine premium pour **LP Beauty Nails**, salon de beauté des ongles à Strasbourg Koenigshoffen.

## Structure

- `index.html` - Page d'accueil
- `services.html` - Prestations & tarifs
- `realisations.html` - Galerie photos
- `a-propos.html` - À propos du salon
- `contact.html` - Contact & réservation
- `mentions-legales.html` - Mentions légales & confidentialité
- `css/style-mobile.css` - Styles mobile-first
- `css/style-desktop.css` - Overrides desktop (≥1024px)
- `js/script.js` - Interactivité (menu, reveal, filtres galerie)
- `sitemap.xml` / `robots.txt` - SEO
- `images/` - Assets visuels

## Stack

HTML5 + CSS3 (variables, grid, flexbox) + JavaScript vanilla. Pas de dépendances.
